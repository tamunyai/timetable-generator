What is the Timetable Generator?

The Timetable Generator is an innovative web-based tool created as the final project for the Programming & GRIT Bootcamp offered by GRIT Lab Africa. It provides students and academic institutions with an automated solution to generate timetables that fit their unique constraints and needs.

The tool allows users to input details such as the number of lecturers, available modules, and the duration of each course to generate an optimal timetable. The system is designed to reduce the time and effort involved in manual timetable creation while also minimizing scheduling conflicts.

Our project leverages Python and Flask for the backend, ensuring efficiency and scalability. With a user-friendly interface and easy-to-use features, the Timetable Generator is an essential tool for students and institutions looking to streamline the scheduling process.

We aim to make academic scheduling easier, more efficient, and accessible for all. This project is the result of months of hard work, collaboration, and problem-solving.
